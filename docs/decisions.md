# Решения и открытые вопросы

## Принято
| # | Решение | Почему |
|---|---|---|
| D1 | Управление WASD + мышь (прицел мышью) | PvP требует точности; клик-управление не подходит |
| D2 | Сервер-авторитарная архитектура с первого дня. Одиночная игра = локальный сервер + клиент | Мультиплеер будет; прикручивать потом почти невозможно |
| D3 | Один этаж построек (крыша скрывается, когда ты внутри) | Проще и подходит виду сверху |
| D4 | Без болезней, настроения, сложной медицины | Пользователь против |
| D5 | Ранения по частям тела отложены (идея: центр модели = голова) | Непонятно, как сделать в топ-дауне; не в MVP |
| D6 | Выживание лёгкое: голод и вода медленные, сытость скорее бонус, животные редкие и пугливые | Должно быть не душным |
| D7 | Сеттинг: трушный постапокалипсис как в Расте, без новомодного «упаша» | Пожелание пользователя |
| D8 | У ботов есть черты (инициатива, агрессия, жадность, терпение, домоседство, скилл), архетип = заготовка черт. Решение о бое — по ставке (кит + груз) | См. `design/06-bots.md` |
| D9 | Директор вайпа: фазы, напряжение, волны, ивенты | См. `design/07-director.md` |
| D10 | Обязателен туман войны / ограниченный обзор | Без него PvP сверху мёртв |
| D11 | Движок: **Godot 4.7 .NET (C#)** — предложено, ждём подтверждения | Лёгкий (~0,5 ГБ против 15–20 ГБ у Unity), без аккаунта, Claude может управлять им из командной строки |
| D12 | Визуал: **2D, вид 3/4**. Персонаж — 4 диагональные позы, левые = зеркало правых (уникальных 2: лицом и спиной). Оружие вращается в руках на 360° отдельно (как в Gungeon). Земля рисуется сверху, объекты с высотой. | Решение пользователя после 3D-прототипа (3D «не вайб»). Одежда = 2 ракурса × кадры, реально для генератора |

## Открытые вопросы
- Камера: строго сверху или под углом ~60°? (решим на прототипе)
- Длина вайпа и что сохраняется между вайпами (настраиваемо, решить позже)
- Чем заменить торговцев (идеи в `design/07-director.md`)
- Механика стабильности вширь — какой вариант (идеи в `design/04-building.md`)
- Размер карты и количество ботов (зависит от производительности, замерим)
