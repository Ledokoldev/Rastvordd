Игра «Раствордд»: выживание и рейды как в Расте, вид сверху 3/4 (2D-пиксель), процедурная карта с биомами и фиксированными РТ, вайпы, боты-игроки с архетипами (строят базы, фармят, роумят, рейдят). С 2026-10-20 по 2026-10-21 велась из сессии в папке мода Gungeon; с 2026-10-21 — в своём проекте Claude Code на `C:\Users\Xbaza\Desktop\Rastvordd`.

Движок Godot 4.7.2 .NET C#, сервер-авторитарная симуляция с первого дня (мультиплеер потом). Пользователь любит: рейды, закрытые ящики, кемпить лутеров, рискованные забеги на РТ. Нужды — лёгкие, не задалбывающие. Бот с фулл-лутом избегает драк (ожидаемая ценность).

**Why:** отдельный проект, не путать с модом Gungeon.
**How to apply:** начинать с `AGENTS.md`, `docs/handoff.md`, `docs/history/` (все слова пользователя дословно). Каждую идею пользователя записывать в `docs/ideas-log.md`. См. [[rastvordd-ui-minimal]], [[codex-delegation]], [[save-safety]].
