# История проекта

- `user-messages.md` — **все сообщения пользователя дословно** (включая присланные посреди работы), с датой и временем.
- `conversation.md` — вся переписка: пользователь и ответы Claude (без вызовов инструментов).
- `work-log.md` — хронология: запросы → что сделано → проблемы и решения, плюс все коммиты.

Обновить выгрузку из журналов Claude Code:
`python scripts/export-history.py <папка ~/.claude/projects/...> <файлы .jsonl по порядку>`
(для нового проекта журналы лежат в `~/.claude/projects/C--Users-Xbaza-Desktop-Rastvordd/`).
