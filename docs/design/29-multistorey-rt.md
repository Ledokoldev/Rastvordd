## 1. Что хотим получить (опоры)
| Опора | Что даёт вертикаль |
|---|---|
| Закрытый ящик | ящик на верхней палубе / в глубине: держать таймер, когда враг может прийти с двух этажей |
| Кемп лутеров | выход с РТ — по лестнице или лифту: предсказуемые точки, но с контрмерами (второй выход, прыжок, люк) |
| Вынести лут | спуск/подъём с грузом — медленный, шумный (лифт, лестница), есть «быстрые и опасные» пути (прыжок, трос) |
| Карго и ивенты | вертолёт и сброс на крышу/площадку (задел «воздух» D60) |
| Боты | охрана и боты-игроки, которые ходят по этажам, слышат сверху и снизу |

Главное отличие от плоской РТ — **вертикальный цикл**: внизу быстро и дёшево, наверху (или в глубине) дорого и опасно, а путь туда один-два.

## 2. Два класса

| | **А. Низкие РТ на острове** | **Б. Отдельные локации** |
|---|---|---|
| Этажей | 2, редко 3 (до 7,8 м) | 3–8 (вверх и/или вниз) |
| Где | на карте, как сейчас | вне острова, своя область координат |
| Вход | дверь, лестница, приставная лестница | переход: лифт, трап, лодка, шлюз («держи E») |
| Обзор с высоты | ограничен радиусом обзора (50–80 м) и туманом — карту не открывает | ограничен стенами локации |
| Примеры | будка диспетчера Депо, вышка, водонапорная башня, контора карьера | нефтяная платформа, хрущёвка, «Объект 42» |
| Сессия | свободно | по правилам локации (окно входа, таймер, эвакуация — как в О42) |

Почему так: условие пользователя «никаких хрущёвок на карте» соблюдается — на острове только низкое, и обзор с крыши ограничен тем же радиусом,
что и на земле. Высокое и глубокое — изолировано, там можно делать сложную планировку без вреда для открытого мира.

## 3. Читаемость (вид сверху 3/4) — главная проблема
Правила, которые делают этажи понятными (часть уже работает по D60):
1. **Активный этаж = твой.** Всё выше тебя под крышей срезано; всё ниже — под полом (видно только через проёмы, лестницы, атриумы).
2. **Вертикальный сдвиг** (как в Zomboid): верхний этаж рисуется выше на высоту этажа и поверх нижних — со стороны видно «башню».
3. **Призрак этажа**: этаж над головой — тонким контуром стен (10 % непрозрачности), чтобы понимать, где лестница наверх. Этаж ниже под
   тобой — затемнён, видны только проёмы и люди, которых ты честно видишь.
4. **Номер этажа и палитра**: у каждого этажа своя доминанта цвета пола (платформа: низ — ржавчина/мокрый металл, середина — жёлтая
   решётка, верх — разметка вертолётной площадки). На лестничной клетке — табличка с номером. В HUD — «Палуба 2 / 3».
5. **Лестницы видно издалека**: подсветка ступеней (тёплая лампа), иконка на миникарте.
6. **Миникарта и карта (G) по этажам**: вкладки этажей, текущий — ярче; люди на других этажах — без точек (честность D32).
7. **Звук подсказывает высоту**: шаги и выстрелы сверху — глухие с низами, снизу — гулкие; в лестничном пролёте и шахте — эхо (Р5).
8. **Высота этажа РТ — 4 м** (пользователь: «4 м на этаж»), у построек игроков — 2,6 м. Сдвиг на экране — по реальной высоте, поэтому
   этажи РТ видно выше построек, это нормально.

Калибровка: прототип «будка Депо» — на нём подобрать прозрачность призрака, силу затемнения нижнего этажа, сдвиг; потом — общий параметр
в `UiTheme`/`Iso`.

## 4. Техника: что добавить к D60

### 4.1 Статичные этажи РТ
Постройки игроков живут клетками 2 м. Для РТ нужно свободное:
- **Плиты** `MapSlab { Floor, Poly, Tex, Z }` — пол любой формы (прямоугольники и многоугольники), неломаемые. Дыры в полу (атриум,
  пролёт, провал) — просто отсутствие плиты. `PlateAt(floor, p)` спрашивает и клетки игроков, и плиты (своя пространственная сетка).
- **Высота этажа локации** — своя (`Location.Storey = 4 м`); `FloorZ(f)` берёт её у места (РТ или постройки).
- **Лестничные марши** `MapStair { A, B (низ и верх оси), Width, FloorLo }` — любой длины (обычный марш 2×5 м: подъём 4 м на 5 м пути),
  разворотные лестницы = два марша и площадка-плита. Логика подъёма — как у лестницы D60 (t вдоль оси → Z, этаж переключается на середине).
- **Лазы** — люк и вертикальная лестница (E, 2 с, руки заняты); **лифт** — движущаяся плита с таймером и звуком (виден снаружи шахты).
- **Ограждения** — парапеты и перила стенами высоты 1 м (уже есть `LowWallH`).
- `MaxFloor` — параметр мира/локации (сейчас 3 для игроков, для локаций — до 8).

### 4.2 Макеты
Формат макетов (`Tier*Layouts.g.cs`, скрипты `mock-*.py`) получает этажи:
```
"floors": [
  { "z": 0, "slabs": [...], "walls": [...], "props": [...], "crates": [...], "guards": [...], "roofs": [...], "lights": [...] },
  { "z": 1, ... }
],
"stairs": [ { "a": [x,y], "b": [x,y], "w": 2, "lo": 0 } ],
"hatches": [...], "lifts": [...], "voids": [...]   // проёмы, через которые видно и стреляют между этажами
```
- Всё, что ставится на этаж: `MapWall.Floor` (уже есть) → сетка этажа; `MapDecor.Floor` + подъём картинки; `LootBag.Floor`, `Actor.Floor` (есть);
  `MapRoof.Floor` — крыша этажа (срезается вместе с этажом); свет с этажом (свет и тени — только своего этажа и ниже через проёмы).
- Генератор: сначала **вертикальный скелет** (лестничные клетки, шахты, атриумы — соосные на всех этажах), потом планировка каждого этажа
  вокруг скелета (как в О42: петли комнат, 2–3 выхода, тупиков ≤ 10 %).

### 4.3 Отдельные локации
- Локация — прямоугольник вне острова (например, центр (3000, 0)), свои границы, своё небо/погода (в помещении — без погоды).
- **Переход** `Portal { From, To, HoldE, Condition, Session }`: держи E 3–5 с (шум, видно на радаре), перенос в точку локации; обратный путь —
  через выход (эвакуация), не обязательно тот же. Подземные уровни считаются снизу: «−4» = этаж 0 локации, поэтому этажи физически друг
  над другом, а звук и пули считаются той же объёмной логикой.
- Снапшот: в локации клиент не получает остров (и наоборот) — дешевле и честнее.
- Сессии и таймеры — по `20-object42.md` (окно входа, 25 мин, эвакуация), для платформы — проще (свободный вход лодкой, ивент по таймеру).

### 4.4 Бой между этажами в РТ
- Пули и обзор — уже объёмные (D60): плиты держат пули, стены — по высоте, проёмы/атриумы пропускают.
- Правило читаемости: **стрельба между этажами — только через «окна» в вертикали** (атриум, пролёт лестницы, люк, край балкона,
  разбитый пол). Через целую плиту — нет. Это и есть «видно и стреляешь в пределах своего этажа», но с осознанными исключениями.
- Гранаты/бомбы в пролёт: брошенное над дырой падает до первой плиты ниже (`LandFloor` уже так делает).
- Прыжок вниз с балкона — урон от высоты (этаж РТ 4 м ≈ −36 HP), быстрый, но дорогой отход.

### 4.5 Охрана (NPC) по этажам
- У охранника — этаж дома и **маршрут по этажу**; на тревогу — бежит по графу лестниц к шуму.
- **Граф лестниц** локации: узлы — концы маршей, люки, лифты; поиск пути = A* по этажу до ближайшего узла → переход → A* на другом этаже.
  Тот же граф — для ботов-игроков (Б4 из `27-floors.md`).
- Тревога по зданию: выстрел слышат этажи в пределах 1 (честный звук), сирена — всё здание.
- Роли: **часовой на крыше** (видит двор, стреляет на 30 м, укрыт парапетом), **патруль лестниц**, **засада у лифта**.

### 4.6 Звук
- Ослабление через плиту: −12 дБ и срез высоких за каждую плиту между тобой и звуком; через пролёт/атриум — без ослабления, с эхом шахты.
- Лифт, лестница из металла, люк — громкие (слышны на 2 этажа).
- Технически: `SimEvent.Z` уже есть; `Acoustics` получает плиты как горизонтальные перегородки.

### 4.7 Боты-игроки
- Таблица «риск/награда» РТ (D41) учитывает вертикаль: ценность верхнего этажа, число путей, охрана на лестницах.
- Действия: подняться по маршрутному графу, взять ящик, уйти другим путём; кемп — у выхода из лестничной клетки или у портала.
- Порог: бот идёт в многоэтажную РТ только при снаряжении на её тир (как сейчас с РТ тира 2).

### 4.8 Производительность
- Обзор и пули считаются только по этажам между стрелком и целью (уже так); снапшот шлёт людей своего этажа ±1 и видимых через проёмы.
- Отрисовка: этажи выше срезанного не создаются как узлы (пул видов по этажу).

## 5. Правила планировки (для любого многоэтажного РТ)
1. **Минимум два пути на каждый этаж** (две лестницы в разных концах или лестница + люк/лифт); единственный вход — только у малых А-РТ.
2. **Вертикальные окна** (атриум, пролёт, балкон) — 1–2 на этаж, всегда видны издалека: это места боя между этажами.
3. **Прострел** 8–18 м на этаже, длинные линии — только наружу (с крыши/палубы во двор, в пределах радиуса обзора).
4. **Вертикальный цикл лута**: этаж входа — малый лут (тир РТ − 1), средний — основной, верх/глубина — закрытый ящик/крейт/сейф.
5. **Отход**: у дорогого этажа есть быстрый опасный выход (прыжок, трос, разбитый пол) и медленный безопасный (лестница).
6. **Шум**: лифт и железные марши выдают, лестница в бетоне — тише.
7. **Свой цвет и номер** у каждого этажа.

## 6. Конкретные РТ

### А1. Будка диспетчера Депо (2 этажа) — первый прототип
- Низ: касса, шкафчики (лут тир 1), дверь во двор; марш вдоль стены.
- Верх: пульт стрелок (сейчас стрелки — на земле, перенести пульт наверх → ради пульта надо подняться), окно на пути, ящик тир 1.
- Охрана: 1 часовой у окна наверху (видит рампу), 1 внизу.
- Проверяет: плиты, марш, срез этажа, охрану на 2-м этаже, читаемость, стрельбу из окна.

### А2. Водонапорная башня (3 уровня) — точка кемпа
- Низ — бетонный стакан с дверью; середина — вертикальная лестница (лаз, 2 с, шумно); верх — круговой балкон под баком, ящик с картой доступа.
- Сильная позиция над дорогой — контрмеры: коктейль в лаз, бомба у основания (лестница рушится → наверху застрял), длинный ствол с земли
  по парапету.

### А3. Контора карьера (2 этажа + балкон)
- Второй этаж — кабинет начальника (сейф), балкон над карьером; кран и контейнер видны с балкона — оттуда прикрывать того, кто в кабине крана.

### Б1. Нефтяная платформа (3 палубы + вышка) — первая отдельная локация
| Палуба | Что | Лут / событие | Охрана |
|---|---|---|---|
| 0 — у воды (z 0) | 4 причала для лодок, сваи, трапы наверх, лебёдки | бочки с нефтью/мазутом (D54), детали тир 1–2 | 2 патруля на мостках |
| 1 — техническая (z 4 м) | лабиринт труб, насосная, мастерская, генератор | крейт под перфокарту II, токарный станок | 3: насосная, мастерская, у трапов |
| 2 — верхняя (z 8 м) | жилой блок, столовая, радиорубка, вертолётная площадка | закрытый ящик (90 с, сирена) на площадке, сейф в рубке | 2 + снайпер на вышке |
| Вышка (z 12–16 м) | буровая вышка, лестница по фермам | точка обзора над всей платформой (только локация) | снайпер |
- Пути наверх: 2 трапа с причалов, внутренняя лестница, грузовой лифт (громкий, 12 с), трос с вышки к воде (быстрый спуск, −15 HP).
- Вертикальные окна: решётчатый пол технической палубы над насосной (видно и стреляют сквозь решётку), проём лифта, край площадки.
- Вход/выход: лодка (подплыть к причалу), уход — на лодке с любого причала. Вертолёт (позже, «воздух»): сброс охраны на площадку при
  запуске закрытого ящика; потом — эвакуация вертолётом.
- Размер: 70×50 м по проекции.

### Б2. Хрущёвка (5 этажей + подвал + чердак) — в конце, по слову пользователя
- 2 подъезда, лестница в каждом, лифт сломан (шахта = быстрый спуск вниз с уроном или по тросу), чердак соединяет подъезды, крыша —
  выход люком.
- Квартиры — шаблоны (1-, 2-, 3-комнатные) с вариантами обстановки; двери: открытые, запертые (ключи в почтовых ящиках), выбитые.
- Лут растёт с этажом; на 5-м — «квартира бандита» (сейф), в подвале — склад (крейт). Охрана — по этажам, на лестничных площадках.
- Окна наружу: стрелять во двор вниз можно, со двора вверх — по окнам; дальность — радиус обзора.

### Б3. «Объект 42» (−1…−4)
- По `20-object42.md`; переводим «два уровня в общей системе координат» на этажи одной локации: шахта = атриум через все уровни,
  3 соосные лестничные клетки, лифты с поверхности = порталы.
- Стрельба через шахту в первом прототипе запрещена (решение О42) — сеткой-ограждением, которая держит пули; позже — открыть.

## 9. Открытые вопросы (решает пользователь)

2. На острове — допустимы ли РТ в 3 этажа (водонапорка), или строго 2?
3. Платформа — свободный вход лодкой или окном по таймеру (как О42)?
4. Стрельба между этажами в РТ — только через «окна в вертикали» (предложение) или везде, где физически видно?
5. Прыжок вниз с этажа РТ (−36 HP с 4 м) — оставить как способ отхода?
