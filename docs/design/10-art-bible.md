# 10 — Арт-библия

Цель (слова пользователя): ассеты по духу как в Rust и Project Zomboid. Постапокалипсис, мрачно, но **хорошо детализировано**. Это очень важно.

## Вид и масштаб
- Вид 3/4 сверху (камера с юга под ~50°), как в Project Zomboid. Земля рисуется сверху, объекты — с высотой.
- **1 метр = 64 px исходника** (в игре 32 px/м при зуме 2 → на экране 64 px/м, то есть 1:1).
- Персонаж ~1,8 м → кадр **128×128**. Дерево 4–6 м → спрайт ~300–400 px в высоту.
- Генерируем крупно (~1024 px), потом скриптом уменьшаем до масштаба.

## Стиль
- Рисованная цифровая живопись, детальная, **без контура**. Не пиксель-арт, не мультяшность.
- Свет сверху-слева, мягкий, пасмурный. Тени на земле не запекаем — их рисует игра.
- Палитра приглушённая: оливково-серые травы, грязно-коричневая земля, бетон, ржавчина, выцветшая краска. Яркие акценты — только у ценного (жёлтые полосы военных ящиков, огонь печи).
- Состояние предметов: потёртое, ржавое, самодельное (металлолом, изолента, доски). Трушный постапок без хайтека.

## Источники
| Что | Откуда |
|---|---|
| Деревья, кусты, камни/руды, ящики, бочки, печь, верстак, хлам, машины, иконки предметов | Генерация через Codex (gpt-image) |
| Земля (трава, грязь, песок, гравий, асфальт, бетон) | CC0-текстуры ambientCG / Poly Haven или генерация бесшовных тайлов |
| Стены и пол построек | готовые паки (itch.io) или генерация модульных кусков |
| Персонажи | позже: 2 позы (лицом / спиной), левые — зеркало |

## Файлы
- Сырые генерации: `assets/gen/<категория>/<id>.png` (не править руками).
- Обработанные для игры: `game/art/<категория>/<id>.png` (кайма убрана, обрезано, масштаб по таблице).
- Список и промпты: `assets/manifest.json`. Генерация: `scripts/gen-assets.ps1`. Обработка: `scripts/process-assets.py`.

## Известные проблемы генерации
- Кайма цветного фона по краям прозрачности → чистим (обрезаем полупрозрачные пиксели и подкрашиваем край по соседям).
- Перспектива у деревьев почти сбоку — допустимо (так в Zomboid и RimWorld).
