## 2. Тематики (что «пахнет» РТ)

| Тематика | Что выпадает чаще | Типичные лутбоксы |
|---|---|---|
| **Быт** | ткань, еда, вода, бинты, лом, мелочь | дешёвый ящик, сундук, пластиковый ящик |
| **Продукты** | консервы, вода, крупа, сахар, сигареты (валюта) | ящик с овощами, термобокс, пластиковый ящик |
| **Медицина** | бинты, аптечки, антирадин, обезбол, шприцы | медкоробка, медшкаф |
| **Инструмент/мастерская** | пружины, шестерни, трубы, изолента, масло, металл | ящик с инструментом, металлический шкафчик |
| **Электрика** | медь, платы, радиодетали, аккумуляторы, линзы, моторы | электрощиток-ящик, алюминиевый кейс |
| **ГСМ/техника** | топливо, масло, резина, трубы, шестерни, моторы | дешёвый ящик, металлический шкафчик, сундук |
| **Оружейка** | патроны, порох, детали т2, обвесы, стволы | ящик патронов, оружейный кейс, военный ящик |
| **Армия** | армейские обвесы, 7,62, гранаты/сачели, бронепластины, армейская одежда | военный ящик, длинный военный, сброс |
| **Ценности** | ценный лом т1–т2, золотые контакты, деньги/документы, карты доступа | дорогой ящик, сейфы |
| **Груз/порт** | всё вперемешку + шанс «джекпота» по журналу грузов | контейнеры порта, дорогой ящик |

Правила:
- **Тир РТ** задаёт, какие лутбоксы вообще могут стоять (т0 — №1–7, 9; т1 — до №14, 18; т2 — всё).
- **Тема РТ ×1,8** к строкам своей тематики (как нынешние профили), остальные строки ×1.
- **Пустая ячейка** допустима: 20–35% ячеек пустые на т0, 10–20% на т2 — обыск остаётся азартом.
