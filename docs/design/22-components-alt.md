Запись запроса: приблизить все девять цепочек документа 19 к мастерским острова 1980-х; дать альтернативы с игровыми различиями, сократить промежуточные детали, выделить экономическое ядро. По прямому ограничению пользователя меняется только этот файл; журнал идей и решения не редактируются. Все расхождения с принятыми решениями ниже — открытые предложения, не отмена решений.

## Рамки

- В0 — руки, В1 — простая мастерская, В2 — механическая обработка, В3 — восстановление заводских узлов. Тир означает доступ и качество, а не возможность выточить любую вещь.
- Сохраняются: исследования за лом, неконструируемые редкие детали, дробовики только из лута, сталь только из лута/переработки, роль публичного переработчика. D54: В3 — 10 стали, оружейный стол — 15; старые 25/20 не возвращать автоматически.
- Токарный — условный комплект мастерской с доступной оснасткой; оружейный стол — сборка и контроль. Наличие стола не заменяет заводскую технологию. Новые отдельные станки пока не нужны.
- Рецепты — «материал + донор + станция». Нет технологических режимов, химических составов, размеров и инструкций изготовления боеприпасов.
- Самодел и заводское изделие — два варианта одного предмета, без отдельного ID для каждого качества. Состояние заводского лута отдельно от качества: ржавый заводской узел тоже требует ремонта.

### Общие игровые различия — числа только для первого прототипа

| Признак | Самодел / восстановление из смешанных деталей | Исправный заводской донор |
|---|---|---|
| Ресурс до ремонта | 70% эталона | 100% |
| Время сборки | ×1,5; шум мастерской | ×1; короткая сборка |
| Цена | Меньше редкого лута, больше обычных материалов и времени | Редкий донор вместо длинного рецепта |
| Надёжность | По умолчанию быстрее изнашивается; осечки как отдельную механику пока не вводить | Дольше работает между ремонтами |
| Информация | Тип и ресурс видны до крафта | Состояние донора видно до расходования |

Проценты не складывать с индивидуальными штрафами ниже: для предмета выбрать один профиль. Самодел не получает больший урон за плохое качество. Запах — описание и короткий маркер работающей установки, не новая система следов для ботов.

### 8 стержневых компонентов / категорий

Дерево, камень, обычный металл и лом остаются базовыми ресурсами; лом — валюта знаний. Ниже именно ограничители решений, а не перечень всего сырья.

| Ядро | За что конкурирует | Основной маршрут |
|---|---|---|
| 1. Пружины | Раннее оружие, ремонт механизмов, магазины | Бочки / бытовые механизмы |
| 2. Оружейные доноры по семействам | Восстановить оружие или переработать | Закрытые крейты / непригодное оружие |
| 3. Легированная сталь | В3, оружейный стол, оружие, броня базы | Опасный лут / публичный переработчик |
| 4. Провод и электрические узлы | Свет, зарядка, питание мастерской | АТС / Подстанция |
| 5. Платы управления | В3 против специального оборудования | АТС / высокие крейты; не нужны каждой лампе |
| 6. Механические доноры | Генератор, инструмент, лодочный двигатель против лома | Гаражи / Депо / побережье |
| 7. Оптические блоки | Прицел против бинокля и переработки | Профильные крейты / командный лут |
| 8. Плотная ткань | Одежда, перевязка, лодка, ремонт | Хозяйственный лут / разбор одежды |

Порох, рейдовые и медицинские комплекты — профильные расходники, топливо — эксплуатационный ресурс. Не привязывать все ветки к единственной плате, подшипнику или медспирту: дефицит должен вести на разные РТ.

## Открытые предложения и экономические ограничения

Вопросы оставлены здесь из-за запрета менять другие файлы; перед внедрением перенести согласованные пункты в «Открытые вопросы» decisions.md.

1. **D46/D49:** заменить крафт оружия из базовых деталей восстановлением совместимых доноров. Дробовики остаются только лутовыми. Отдельно решить происхождение АН-94 и других поздних моделей в сеттинге 1980-х.
2. **D49:** новые способы разборки и восстановления не обходят старт выдачи деталей В3 с 5 ч и предел 5 деталей/мир/ч. Сохранять семейство и редкость при переименовании. Альтернативная сборка не превращает обычную коробку АК в комплект элитного АН-94.
3. **D54:** аптечка/шприц без топлива; масло не из угля; аккумулятор становится полезным, а не только ценным ломом; ручная динамо не питает колонну. Это изменения рецептов/назначений, требующие отдельного согласования.
4. **D53/D54:** отделить баллистическую броню от защиты от загрязнения; не обещать универсального радиолечения. До согласования старые характеристики остаются действующими.
5. **Цена пути:** для АКМ сохранить ориентир около 685 лома на изучение и 6–8 ч до первого крафта; нижняя опора стали — 10 В3 +15 стол +25 АКМ =50. Удалённые шестерни и пружины не компенсировать автоматически ещё большим числом предметов: сначала оценить цену доноров.
6. **Лут:** новые источники заменяют часть старой выдачи равной ожидаемой ценности. Готовый предмет экономит сборку, самодел экономит редкий лут. Профильная РТ даёт преимущество маршрута, не гарантированный полный набор за один заход.
7. **Разборка:** возврат только части реально вложенных материалов, не более 50% обычного сырья; для партий считать на одну вещь. Восстановление не обнуляет происхождение, квоту и качество; циклы «собрать → разобрать» не увеличивают сталь/лом.
