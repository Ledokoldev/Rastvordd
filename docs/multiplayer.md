# Мультиплеер: игра с друзьями (D73)

## Как устроено
- **Сервер — игра на ПК хоста.** Мир с ботами считает только он (сервер-авторитарная симуляция, `LocalServer`).
- **Друзья — клиенты.** Мир не считают: шлют серверу ввод (`InputCmd`, 30 раз в секунду), получают снимки (`Snapshot`) и рисуют их.
  Карту клиент строит сам по зерну сервера и сверяет отпечаток (`NetProto.MapHash`).
- **Транспорт:** TCP, порт **7777**, до 8 друзей. Сначала был ENet/UDP, но через VPS/VPN UDP-пакеты больше ~1200 байт режутся (MTU), а TCP подстраивается сам. Снимок — каждый тик, только изменившиеся поля, сжатие Brotli.
  Клиент держит запас в 2 снимка, примерно 66 мс: так картинка не дёргается от рывков сети.
- **VPS — только проброс** TCP 7777 до ПК хоста через [frp](https://github.com/fatedier/frp). Ботов и игру на VPS не запускаем.
  frpc на ПК хоста сам подключается к VPS. Порт на роутере и белый IP не нужны.

```
друг ──TCP 7777──▶ VPS (frps) ══туннель (TCP 7000)══ ПК хоста (frpc) ──▶ 127.0.0.1:7777 игра-сервер
```

## Хост (ты)
1. Запустить **«Сервер для друзей.cmd»**: своя игра с 20 ботами и обычным сохранением, сервер открыт сразу.
   Или в обычной игре: **Esc → «Сеть» → «Открыть сервер»**.
2. Если в `tools\frp\` лежат `frpc.exe` и `frpc.toml` (см. ниже), cmd сам поднимет проброс.
3. Друзья, которые зашли, сохраняются в твоём мире по имени: зашёл снова — продолжает тем же персонажем.
   Вышел — персонаж остаётся стоять в мире.
4. Пока сервер открыт, мир идёт только с обычной скоростью (без ускорения).

## Друг (клиент)
- **«Подключиться к другу.cmd»** → адрес `IP_VPS:7777` и имя.
- Или в игре: **Esc → «Сеть»** → адрес и имя → **«Подключиться»**. Своя игра перед этим сохраняется.
  «Отключиться» — назад в свой мир.
- Клиент **никогда** не пишет сохранение и не может сделать вайп чужого мира.
- Имена «Игрок» и «… (бот)» заняты. Если связь с сервером пропала, игра через 3 с вернёт в свой мир.

## Как настроено сейчас (2026-11-17)
- На VPS стоит служба `frps` v0.72.0 (`/etc/frp/frps.toml`, `systemctl status frps`), порт туннеля 7000/tcp, игровой 7777/tcp.
  VPN на том же VPS не тронут, ufw не включали.
- У хоста `tools\frp\frpc.exe` и `tools\frp\frpc.toml` с адресом и токеном. Папка в `.gitignore`: репозиторий публичный, токен туда нельзя.
  Хостить с другого ПК — скопировать туда папку `tools\frp` целиком.
- Друзья подключаются к `IP_VPS:7777`. Адрес — у хоста, в репозиторий его не пишем.

## Настройка VPS (один раз)
Пример для Ubuntu/Debian, пользователь с sudo. `ТОКЕН` — любая длинная случайная строка, одна и та же на VPS и у хоста.

```bash
# 1. скачать frp (свежую версию — со страницы releases)
cd ~ && wget https://github.com/fatedier/frp/releases/download/v0.72.0/frp_0.72.0_linux_amd64.tar.gz
tar xzf frp_0.72.0_linux_amd64.tar.gz && sudo cp frp_0.72.0_linux_amd64/frps /usr/local/bin/

# 2. конфиг сервера
sudo mkdir -p /etc/frp && sudo tee /etc/frp/frps.toml >/dev/null <<'EOF'
bindPort = 7000
auth.token = "ТОКЕН"
allowPorts = [{ single = 7777 }]
EOF

# 3. служба: стартует сама после перезагрузки
sudo tee /etc/systemd/system/frps.service >/dev/null <<'EOF'
[Unit]
Description=frps (Rastvordd relay)
After=network-online.target
[Service]
ExecStart=/usr/local/bin/frps -c /etc/frp/frps.toml
Restart=always
[Install]
WantedBy=multi-user.target
EOF
sudo systemctl daemon-reload && sudo systemctl enable --now frps

# 4. брандмауэр: туннель и игровой порт
sudo ufw allow 7000/tcp && sudo ufw allow 7777/tcp
```
Если у хостера есть свой брандмауэр в панели (security group), открыть там те же порты: **7000/tcp** и **7777/tcp**.

## Настройка ПК хоста (один раз)
1. Скачать `frp_…_windows_amd64.zip` с той же страницы releases. Положить `frpc.exe` в `tools\frp\`.
   Windows Defender иногда ругается на frp: разрешить файл.
2. Создать `tools\frp\frpc.toml`:
```toml
serverAddr = "IP_VPS"
serverPort = 7000
auth.token = "ТОКЕН"

[[proxies]]
name = "rastvordd"
type = "tcp"
localIP = "127.0.0.1"
localPort = 7777
remotePort = 7777
```
3. Проверка: запустить «Сервер для друзей.cmd». В окне frpc должно появиться `start proxy success`.
   Друг подключается к `IP_VPS:7777`.

## Если не подключается
- «нет ответа от сервера»: не запущен frpc или frps, закрыт 7777/tcp на VPS, у хоста не открыт сервер (Esc → «Сеть»).
- «другая версия игры»: у друга должна быть та же сборка, что у хоста (тот же коммит).
- «Карта сервера не совпала»: другая сборка или другой `balance.json`.
