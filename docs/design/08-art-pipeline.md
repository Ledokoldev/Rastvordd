# 08 — Арт и ассеты

## Подход (предложено, оценить на прототипе)
3D-модели + камера сверху. Выглядит как 2D, но одежда надевается на скелет и работает со всеми анимациями.
Референсы вида: RimWorld, Project Zomboid (2D-мир + 3D-персонажи), Last Day on Earth.

## Источники
- **Анимации:** Mixamo (бесплатно, автоскелет, тысячи движений).
- **Модели:** Quaternius (CC0), Kenney (CC0), Synty POLYGON Apocalypse (платно, недорого со скидками).
- **Тайлы и текстуры:** Kenney, itch.io, OpenGameArt (проверять лицензию каждого пака), ambientCG / Poly Haven (CC0 текстуры).
- **Генерация (ComfyUI пользователя):** иконки инвентаря, текстуры, декали, концепты; «картинка → 3D» (Hunyuan3D, TRELLIS) для пропсов (камни, ящики, бочки, хлам).

## Правило единого стиля
Сразу зафиксировать палитру, масштаб, толщину контура и освещение. Всё сгенерированное и купленное приводить к ним.

## Пользователь делает сам
Оружие, кирки, камни, иконки — на локальном генераторе.
