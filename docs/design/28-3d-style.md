# 28 — Стиль 3D-моделей: советский постапок (2026-11-13)

Продолжение арт-библии (`10-art-bible.md`) для 3D. Слова пользователя: «у нас постапокалипсис советский — стиль сохранить, модели оригинальные и красивые, но не перегруженные».

## Опоры
1. **Советская утилитарность.** Массивно, просто, на века: толстый металл, сварные уголки, заклёпки, ручки-скобы, трафаретные надписи и номера. Ничего изящного.
2. **Постапок — поверх.** Краска выцвела и облупилась, под ней ржавчина; ремонт подручным (доска на проволоке, лист жести на болтах, изолента). Без хайтека и «упаша» (D7).
3. **Не перегружать.** Силуэт читается сверху под 58° с 15–25 м: 3–6 крупных частей + 2–4 детали, которые видно (ручки, заклёпки по углам, трафарет). Мелочь, которой не видно с камеры, — не моделировать.
4. **Оригинальность.** Свои формы «по мотивам» эпохи, без копий реальных брендов и без моделей из других игр.

## Палитра (матовая, приглушённая)
| Цвет | Где |
|---|---|
| Защитный зелёный (хаки, `#4b5a3a`…`#5d6b45`) | ящики, техника, военное |
| Выцветший голубой (`#6f8a96`) | бытовое, станки, шкафы |
| Бетон, серый (`#8a8a84`) | конструкции |
| Ржавчина (`#7a4a2a`…`#9a5a32`) | края, низ, сварка |
| Дерево серое выветренное | доски, ящики, ручки |
| **Акцент** — красный (`#8e2b22`), жёлто-чёрная полоса | только ценное и опасное: огнетушитель, газ, военный ящик. Не больше одного акцента на модель |

## Геометрия и сетка
- 1 ед. = 1 м, Y вверх, опора на земле в центре, «перед» — +X (как у всех моделей, `27-3d-client.md`).
- **Фаски на всех рёбрах** (bevel 1–2 сегмента, 5–15 мм): даже простая коробка ловит свет — главная «дорогая» деталь при малом бюджете.
- Бюджет треугольников: мелкое (бочка, баллон) — до 1,5 тыс.; среднее (ящик, печь, верстак) — до 4 тыс.; крупное (станок, генератор) — до 8 тыс.
- Нормали — сглаживание по углу (30°), чтобы фаски были мягкими, а плоскости — плоскими.

## Материалы
Общая библиотека — `scripts/blender/soviet_kit.py` (`MATS`): CC0-текстуры Poly Haven 1k (цвет, нормали, шероховатость) + оттенок под палитру. Модель берёт 2–3 материала из библиотеки, свои не заводит. Развёртка — кубическая проекция в метрах (одинаковая плотность на всех моделях).

## Конвейер
`scripts/blender/fetch-textures.ps1` (текстуры) → `tools/blender/…/blender.exe -b -P scripts/blender/build.py -- [имя…]` → `game/art3d/own/<имя>.glb` + превью `assets/3d-preview/<имя>.png` (рендер под углом камеры игры).
Порядок поиска модели в игре: `own/` → `hq/` (Poly Haven) → сгенерированная.
