## 2. Новые ассеты (листы анимаций)

оформление `fx_framing`/`fx_style` в том же манифесте). Обработка: `python scripts/process-assets.py --manifest=assets/manifest_vfx.json`

привязки `anchor` не прыгают), своя палитра 24 цвета, альфа ступенчатая (`hard` 0/255, `soft` для дыма 0/150/255).

## 3. Система в клиенте (`game/src/Client/Vfx.cs`)

- Пул спрайтов `Sprite2D` (Hframes = число кадров) в `_world` с y-sort: точка узла — на земле, высота — смещением
  спрайта вверх, поэтому дым у стены корректно перекрывается постройками перед ним. Предел — 600 одновременных эффектов,
  короткие эффекты вне кадра (+запас) не создаются.
- Материал дыма, пыли и попаданий — `VisionFx.ObjectMat` (вне обзора серые, как мир). Светящиеся части (огонь, вспышки,
  ракета) — без затенения обзором, ночью их подсвечивает собственный `PointLight2D` (как `Art.FireLight`) — огонь,
  взрывы и вспышка выстрела выдают позицию ночью.
- Угольки над огнём — `CpuParticles2D` с листом `embers` (анимация частиц по кадрам).
- Пиксель-снаппинг: позиции округляются до целых пикселей, масштаб спрайтов только целый.

## 4. Куда подключено

| Событие / объект | Было | Стало |
|---|---|---|
| Выстрел (Shot) | жёлтый круг | `muzzle_pistol/rifle/shotgun` по стволу, ПБС (`Value=1`) — `muzzle_suppressed`; повёрнут по выстрелу; пороховой дымок; свет |
| HitActor | красный/жёлтый круг | `hit_blood` (стилизованные капли), шлем/пластина — `hit_sparks` |
| HitWall | жёлтый круг | материал по точке: ресурс рядом / вид стены карты (`WallKind`) → искры, щепки, крошка + пыль |

| Explosion (сумка, C4) | два круга | `explosion_small/big` + `shockwave` + кольцо пыли + столб `smoke_black` + подпалина `decal_burnt_spot` на 60 с + свет |

Отладка: действие сценария `--do=N:vfxall|vfxboom|vfxmolotov|vfxflare|vfxfire` — эффекты рядом с игроком.

Производительность: пул ≤ 600 спрайтов, короткие эффекты вне кадра не создаются, одновременно ≤ 8 вспышек света,
тени — у первых трёх. Днём вспышки света слабее (×0,3), ночью в полную силу.

Не сделано / на потом: трассеры остались линиями; костра как объекта в игре нет (лист `fire_small` готов);
горящих обломков/вертолёта нет (`fire_big` готов); `smoke_cloud` (дымовая шашка) готов, но предмета нет;
частицы радиации не делались; ракету не видно, если она за краем экрана (нужна метка на HUD/миникарте).
