# Фич-лист (бэклог)

Сюда — задачи, которые пользователь попросил записать «на потом». Сделанное вычёркивается со ссылкой на коммит.
Полный журнал всех идей — `docs/ideas-log.md`, состояние прогрессии — `docs/design/progression/progression.html`.

## Стрельба и хитбоксы

1. **Пули сквозь мелкие препятствия (камни, перегородки, низкие заборчики, кусты).** Сейчас такие штуки
   полностью ловят пулю. Нужно: пуля, вошедшая в мелкое препятствие, с шансом 30–40% застревает в нём,
   иначе пролетает насквозь (как будто прошла над краем/в щель). Делать просто и без багов: бросок
   один раз на пулю при первом касании этого препятствия (запомнить id препятствия в пуле), шанс — свойство
   препятствия (камень 40%, перегородка/забор 30%, куст 10%); стены, двери, крупные камни и техника — как
   сейчас, всегда ловят. Пролёт виден: искры/щепа на краю, звук рикошета не обязателен.
2. **Хитбоксы объектов по пикселям спрайта.** Брать спрайт объекта, строить маску непрозрачных пикселей
   (с учётом масштаба 32 px/м и вида 3/4: в маску идёт «подножие» — нижняя часть силуэта, которая стоит на
   земле, а для пуль — весь силуэт по высоте), упростить в несколько прямоугольников/полигон и хранить как
   статический хитбокс рядом с ассетом (генерировать скриптом при импорте, не считать в рантайме). Если
   сложно — сначала для пропсов РТ и деревьев, потом для построек.
3. **Хитбокс персонажа по модели.** Попадание считать по реальной фигуре персонажа (голова, корпус, руки,
   ноги из рига), а не по кругу; зоны попадания (голова/корпус/конечности) — по той же фигуре.
4. **Свои хитбоксы у пуль** (радиус пули/дробины по калибру), чтобы попадание по краю считалось честно.

## Звук

5. **Проверка направления на слух** — режим «Угадай направление» в «Полигон — звук»: звук играет с
   одного из 36 направлений (через 10°), игрок наводится и жмёт — считается ошибка в градусах, путаница
   перед/зад, статистика по типам звуков и дистанциям (делается в ветке sandbox-modes).

## Интерфейс

6. **Выделение (подсветка цели под курсором)** — сейчас «отвратительное», переделать: аккуратный контур
   по силуэту объекта вместо текущего.

## Баланс

7. **Дроп одежды с охраны РТ тира 2** — сейчас почти фуллсет армейки: не больше 1–2 вещей, армейка — в
   основном из ящиков и сбросов.
