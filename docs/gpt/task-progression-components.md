# Задача для Астры: прогрессия через компоненты — цепочки крафта, предметы, лут (+ ассеты)

Ты — геймдизайнер «Раствордд» (top-down выживание в духе Rust, постсоветский остров 1980-х, тиры 0–3, РТ-монументы,
«Объект 42»). Нужно придумать **цельный, играбельный слой прогрессии через компоненты**: из чего крафтятся вещи,
откуда берутся компоненты, какие цепочки ведут от «камень и палка» до топового снаряжения, и какой лут где лежит.

## Что сделать
1. **Документ** `docs/design/19-components.md` (по-русски, конкретно, с числами):
   - 25–40 **компонентов** (механика, электроника, химия, ткань/кожа, металлургия, оптика, медицина, топливо): название, тир, откуда (разбор/переработчик, лут РТ, крейты, охрана, станки, добыча), для чего.
   - **Цепочки крафта** по тирам 0→3: сырьё → полуфабрикат → компонент → вещь. Минимум 8 цепочек (оружие, броня, медицина, взрывчатка, электричество/топливо, стройка, инструменты, транспорт/лодка). Указать станок (верстак 1–3, печь, токарный, переработчик, перегонка — что уже есть в коде, и что предложить новое).
   - **Лут-таблицы**: что падает на РТ тира 0/1/2/3, в «Объекте 42», в аирдропе, с охраны (дроп одежды с охраны тира 2 — не больше 1–2 вещей, без фуллсета), в мусоре/бочках.
   - **Узкие места и решения игрока**: какие 4–6 компонентов — «бутылочные горлышки», ради которых идут на РТ; что можно получить двумя путями (дорогой крафт vs опасный лут).
   - Не ломать то, что уже есть в коде: существующие id предметов и рецепты переиспользуй, новое — помечай «НОВОЕ».
2. **Таблица для кода** `docs/design/19-components.json`: `{"components": [{"id","name","tier","sources":[...],"used_in":[...]}], "recipes": [{"out","n","station","cost":[["id",n],...],"time"}], "loot": {"<место>": [["id", шанс, мин, макс], ...]}}`. id — латиницей в стиле существующих (`comp_*`, `item_*`).
3. **Ассеты** `assets/manifest_components.json` — по образцу формата `manifest_items3.json` (поля `id`, `cat`, `desc`, и т. п. как там): иконки/предметы для **всех НОВЫХ** компонентов и вещей из документа (только новых, существующие не дублировать). Описания `desc` — на английском, в стиле существующих (Soviet 1970s–1990s, worn, no text/logos).
