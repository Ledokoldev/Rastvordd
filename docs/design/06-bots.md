# 06 — Боты

## Класс A — простые NPC
Учёные или охрана на РТ, животные. Машина состояний: патруль → заметил → бой → преследование → возврат. Засыпают, когда рядом никого.

## Класс B — боты-игроки
Проходят тот же путь, что игрок: голый старт → фарм → база → РТ → бой → рейды.

### Черты (0–1, задаются при спавне)
- **инициатива:** как далеко готов идти и как быстро реагирует на ивенты;
- **агрессия:** нападёт или пройдёт мимо;
- **жадность:** рискнёт ли ради лута;
- **терпение:** готов ли кемпить и ждать;
- **домоседство:** сколько времени уделяет базе;
- **скилл:** точность, реакция, тактика, оценка ситуации.

### Архетипы (заготовка черт + разброс), по реальным игрокам Раста
- **Роумер:** высокая инициатива и агрессия, ноль домоседства. Носится и бьёт всех.
- **Фермер:** строит большую базу, выходит за ресурсами.
- **РТ-шник:** живёт рейсами на РТ.
- **Кемпер:** сидит на выходах с РТ и дорогах.
- **Рейдер:** копит взрывчатку, ищет слабые базы.
- **Крыса:** лезет в открытые базы, ворует, кемпит двери.
- **Бомж:** голый с камнем. Атмосфера и лёгкая добыча.

### Выбор цели
Utility AI: голоден / мало ресурсов / есть пушка → РТ / вижу слабого → атака / база слабая → апгрейд / ивент рядом → реакция (с весом по инициативе).
Базы строятся по **шаблонам** (10–20 заготовок), поэтапно апгрейдятся.
**Память:** бот не видит карту целиком, помнит базы, места смертей, лут и обидчиков.

### Риск: ставка определяет агрессию
- **Кит** — то, в чём вышел (готов рисковать). **Груз** — то, что несёт домой (ставка).
- Ставка считается **относительно богатства бота**.
- При встрече: выигрыш = видимая ценность врага × шанс победы; проигрыш = (кит + груз) × шанс поражения. Решение с поправкой на риск-толерантность. Тупые боты оценивают с ошибкой.
- **Режим «груз»** (при большой ставке, у агрессивных порог выше): обходит дороги, идёт лесом и ночью, приседает, стреляет только при нападении или в углу.
- После сдачи лута снова охотник.
- **Исключения:** загнали в угол → дерётся; лёгкая добыча (голый) → может убить даже с грузом; «жадный идиот» → небольшой шанс полезть в драку с фулл лутом; **тильт** → убитый с грузом запоминает убийцу и мстит (охота, рейд).
- **Обратная сторона:** груз видно (рюкзак, выход с РТ, звук взлома), кемперы и рейдеры охотятся за гружёными. Экосистема хищник/жертва.

### Дуо (опционально)
Два бота с общей базой и целью, один ведущий. Не больше двух.

### Производительность
- LOD-симуляция: рядом с игроком — полный расчёт, далеко — упрощённая статистическая жизнь.
- Многопоточность для поиска пути и восприятия. GPU для логики решений не подходит (много ветвлений), может пригодиться для массовых вычислений (обзор, поля потоков).
