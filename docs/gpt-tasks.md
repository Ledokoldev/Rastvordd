# Задачи для ChatGPT (на 1 день подписки)

Задачи независимые: GPT может делать их параллельно с Claude, не трогая код.
**Как использовать:** в новом чате вставь блок «Контекст», потом текст задачи. Ответ сохрани в `docs/gpt/<номер>-<название>.md` (или `.json`). Claude потом прочитает его и встроит в дизайн.

Если поставишь Codex CLI и войдёшь через ChatGPT-аккаунт, он сам прочитает `AGENTS.md` в этой папке. Тогда дай ему ту же задачу и попроси сохранить результат в `docs/gpt/`. **Код игры ему не давать**, чтобы не конфликтовать с Claude.

---

## Контекст (вставлять перед каждой задачей)
```
Я делаю игру «Раствордд»: Rust (Facepunch) с видом сверху. Процедурный остров с биомами и готовыми префабами РТ (monuments), фарм ресурсов, базы на тайловой сетке в один этаж, рейды, вайпы. Карту населяют боты двух классов: простые NPC на РТ и боты-игроки, имитирующие реальных игроков Раста (архетипы: роумер, фермер, РТ-шник, кемпер, рейдер, крыса, бомж; черты: инициатива, агрессия, жадность, терпение, домоседство, скилл; агрессия падает, когда бот несёт ценный груз). Директор вайпа (как рассказчик RimWorld) управляет фазами, ивентами и волнами ботов. Опоры игры: рейды, закрытые ящики, кемп лутеров, вынести лут и реализовать, карго и ивенты. Сеттинг: трушный постапокалипсис без новомодного хайтека. Выживание лёгкое, не душное. Движок Godot 4 C#, 3D-модели low-poly с камерой сверху. Делаю один (+ ИИ).
```

## 1. Подборка ассетов
```
Найди бесплатные (CC0/CC-BY) и недорогие (до ~30$) ассеты для low-poly 3D постапокалипсиса с видом сверху: модульные персонажи (совместимые с Mixamo / humanoid-скелетом), оружие, постройки и стены, руины, машины, растительность, камни и руды, текстуры земли (трава, песок, снег, асфальт), UI-иконки. Для каждого: название, автор, ссылка, лицензия, цена, формат (FBX/GLB/OBJ), стиль, совместимость с Godot 4. Таблица по категориям. Отметь паки, которые сочетаются по стилю между собой. Отдельно — где взять звуки (выстрелы, шаги, удары по ресурсам, взрывы) бесплатно.
```

## 2. РТ (monuments)
```
Придумай 16–20 РТ для карты в духе Rust, но своих (не копии). Для каждого: название, размер (мелкий/средний/крупный и примерно в метрах), где спавнится (биом, у воды, у дороги), уровень лута (1–3), охрана (тип NPC, количество), особенность прохождения (карты доступа, рычаги, радиация, паркур, таймер), чем он интересен для PvP (где кемпят, откуда заходят, где опасно выходить с лутом), примерная планировка словами. Добавь 3–4 ивентовых РТ (аналог карго, вертолёта). Каждый РТ должен поддерживать опоры игры.
```

## 3. База предметов (данные)
```
Составь черновую базу предметов в JSON по схеме:
{"id":"", "name_ru":"", "category":"resource|component|tool|weapon|ammo|clothing|armor|medical|food|building|deployable|explosive", "tier":1-4, "stack":0, "craft":{"workbench":0-3, "time_s":0, "cost":{"id":количество}} | null, "stats":{}}
Ресурсы (дерево, камень, металлическая руда, металл, сера, порох, ткань, кожа, топливо, МВК и т. д.), компоненты, инструменты, 15–20 видов оружия по тирам (stats: damage, fire_rate, magazine, reload_s, spread, range_m, noise_m), патроны, одежда и броня по слотам (stats: bullet_protection, cold_protection, speed_penalty), медицина, еда, рейдовые средства (stats: damage по уровням стен: twig/wood/stone/metal/hqm). Баланс прогрессии как в Расте, но без новомодного хайтека.
```

## 4. Сценарии поведения ботов (для тестов ИИ)
```
Составь 30 конкретных ситуаций для тестирования ботов-игроков и для каждой опиши, что сделает бот каждого архетипа (роумер, фермер, РТ-шник, кемпер, рейдер, крыса, бомж) и почему. Примеры ситуаций: «вышел с крупного РТ с фулл лутом и видит одного голого», «слышит стрельбу в 150 м», «объявлен закрытый ящик в 400 м», «его база под рейдом, он в 600 м», «встретил равного по киту при пустом инвентаре», «ночь, у него 20% HP». Отдельно предложи числовые значения черт (0–1) для каждого архетипа и разброс.
```

## 5. Промпты для иконок (ComfyUI)
```
Сделай систему промптов для генерации иконок инвентаря в едином стиле (постапокалипсис, вид предмета под углом 3/4, прозрачный или однотонный фон, единое освещение, читаемый силуэт на 64×64). Дай: 1) базовый стилевой промпт и негативный промпт, 2) шаблон «предмет + материал + состояние», 3) готовые промпты для 60 предметов (ресурсы, инструменты, оружие, патроны, одежда, медицина, еда, взрывчатка). Учти SDXL/Flux.
```

## 6. Замена торговцев
```
В Rust торговцы на аутпосте скучные. Предложи 8–10 механик, которые заменят торговлю и сделают «реализацию лута» рискованной и интересной (например: чёрный рынок с публичным сбросом, контракты, аукцион, переработчик в спорных зонах). Для каждой: как работает, какую опору игры усиливает, как в ней участвуют боты, риски для баланса. Выбери 2 лучшие и обоснуй.
```

## 7. Стабильность вширь
```
В игре базы строятся в один этаж на тайловой сетке. Нужна механика, которая не даёт бесконечно расширять базу и ставить тысячи дверей, но не душит строительство. Предложи 5–6 вариантов (радиус шкафа, прогрессивное содержание, опоры и пролёты, и свои), для каждого — формулы, плюсы и минусы, как он влияет на рейды и как его поймут боты, строящие по шаблонам. Порекомендуй комбинацию.
```
