# Роадмап «Раствордд» (на 2026-10-21)

Порядок — по важности для опор игры. Каждый пункт заканчивается проверкой в игре.

## Сделано
- **Этап 0.** Сервер-авторитарная симуляция (локальный сервер в одном процессе), WASD + мышь, стрельба с разбросом, туман войны на сервере, охранники РТ (присматриваются, неточные первые очереди), лут с трупов и ящиков, смерть и пляж.
- **Камера и обзор.** Вид 2D 3/4, 4 диагональные позы (левые — зеркало). ПКМ — прицеливание (уже конус, дальше обзор, меньше разброс, медленнее шаг). Спринт только вперёд.
- **Этап 1.** Голод/вода (лёгкие), ресурсные узлы, пояс 6 слотов, крафт по Q с очередью, печь (руда → металл/сера, уголь), верстак, установка ЛКМ.
- **Арт.** Конвейер Codex → пикселизация (32 px/м, общая палитра) → игра. ~120 ассетов: деревья, руды, растения, предметы, 13 тайлов земли/стен, 60+ иконок, 25 видов оружия, огонь, декали.
- **Мир.** Остров 400×400 м с биомами (поле, лес, тайга со снегом, пустошь, болото, пляж), вода непроходима, ресурсы по биомам, спавны на пляжах. Земля одним шейдером: рваные переходы, рельеф светотенью по высотам, пена у берега.
- **Свет.** Смена дня и ночи (20 мин на сутки), ночью обзор на 40% короче, свет от печи и вспышек выстрелов.
- **Звук.** Синтезированные заглушки: выстрелы, удары по дереву/камню/руде, взмах, попадание, шаги по траве/гравию, лут, крафт, треск печи; фон — ветер, прибой, птицы днём, сверчки ночью.
- **Персонаж.** Сгенерированный лист ходьбы (4 кадра лицом, 4 спиной) для игрока («голый») и охраны РТ (брезент, сталь на груди).

## Дальше (предложение порядка)
1. **Персонаж дальше.** Одежда слоями (2 ракурса) или готовые листы под каждый комплект; кадры удара/стрельбы; анимация смерти.
2. **Звуки по-настоящему.** Скачать CC0-паки (см. ниже), заменить заглушки, добавить фоновый эмбиент по биомам (ветер, птицы, прибой).
3. **Этап 2 — строительство и рейды.** Сетка, уровни стен (солома → дерево → камень → металл → МВК), двери, замки, шкаф. Стабильность вширь по рекомендации Астры (`docs/gpt/05-stability.md`: радиус шкафа 8 тайлов + бюджет конструкции 360 + мягкое содержание). Рейдовые средства.
4. **Рельеф с геймплеем.** Высота на сервере уже есть: с холма видно дальше, крутые склоны медленнее, скалы-обрывы как объекты (закрывают обзор, дают укрытие).
5. **Больше РТ.** Взять 4–6 из 18 придуманных Астрой (`docs/gpt/01-monuments.md`) и собрать префабами; раскладка генератором по правилам.
6. **Этап 4 — первый бот-игрок.** Полный цикл: голый старт → фарм → база по шаблону → РТ → бой; ставка (кит + груз) решает, драться ли. Сценарии для тестов — `docs/gpt/03-bot-scenarios.md`.
7. **Этап 5 — экосистема.** Архетипы, дуо, волны, директор вайпа, закрытый ящик, карго, замена торговцев (Астра советует: спорный переработчик + чёрный рынок с публичным сбросом, `docs/gpt/04-traders.md`).
8. **Одежда и броня, медицина.** Цифры — черновик `docs/gpt/02-items.md`.
9. **Производительность.** Пространственная сетка для коллизий/обзора, LOD-симуляция ботов, замер «сколько ботов тянет комп».
10. **Сеть.** Тот же сервер за ENet, клиентское предсказание движения.

- **freesound.org** с фильтром CC0 — эмбиенты, выстрелы, природа (нужен аккаунт — заводишь ты).
