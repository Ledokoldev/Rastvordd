# Свои названия вместо растовских — черновик на утверждение

Решение D19: уходим от копирки Раста через названия и предметы. Первый вариант в каждой строке — мой совет.
Отметь, что берём (или впиши своё), — заменю в игре разом.

## Термины и механики
| Сейчас (как в Расте) | Варианты |
|---|---|
| РТ | **Объект** · Точка · Зона |
| Вайп | **Сезон** · Цикл · Заход |
| Шкаф (TC) | **Межевой столб** · Знамя · Сундук-заявка |
| Содержание / гниение | **Подать** (столб «ест» ресурсы) · Износ |
| Закрытый ящик | **Опечатанный сейф** · Пломба · Бронеящик |
| Карго | **Баржа** · Транспорт · Конвой |
| Охрана РТ («учёные») | **Сторожа** · Артельщики · Смотрители |
| Чертёж (план постройки) | **Разметка** · Чертёж · Шнур |
| Молоток | **Киянка** · Молоток |
