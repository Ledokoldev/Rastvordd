# Оружие, компоненты, прогрессия (D46, 2026-10-22, версия 2 — после правок пользователя)

## Решения пользователя
- Прогрессия по верстакам как в Расте; изучение за лом по ветке: **до калаша ≈700 лома суммарно** (не 400 за узел).
- **Дробовики не крафтятся вообще** — только РТ, аирдропы, тир-3 локации (с малым шансом). Двустволка — только найти.
- Самоделка (кустарный ПП) — топ внутри тира 1, в конце ветки верстака 1.
- Тир 3: **никакой М16/«берсты»** — российский аналог с отсечкой: **АН-94 «Абакан»** (очередь по 2).
- Калибры: пистолетный, 5,45 (вместо 5,56 — российский), 7,62, плюс 12 калибр для дробовиков.
- Магазины: **либо увеличенный, либо быстросъём (спарка)** — без комбо.
- Прицелы: коллиматор, 2×, 4×. Механику прицеливания обсудим позже (у пользователя есть идеи).
- Первый ствол тира 3 через верстак — 6–8 ч. Позже: шанс найти один топ-ган на топ-РТ в начале вайпа (повод роумить).
- Нужен «очиститель» как в Арке (обратный переработчику): из базовых компонентов — более качественные, но **не всю цепочку с нуля**: есть некрафтящиеся компоненты, и чем дороже компонент, тем больше в его рецепте доля некрафтящихся.
- Фиксированный набор компонентов, описания для всего, красивые ассеты для всего (стволы, компоненты, обвесы, аирдропы/ивенты).
- Больше способов добыть оружие: РТ разных тиров, бочки на них, быстрые ивенты типа аирдропа.

## Принципы баланса
1. В каждом тире несколько стволов с **разными ролями**; внутри тира — обмен, а не «один лучше всех».
2. Следующий тир лучше **в своей роли**, предыдущий остаётся рабочим и дешёвым.
3. Полуавтоматический пистолет — самый слабый по DPS в своём тире (антипешка).
4. Лутовое оружие (дробовики, элита) — специалисты, а не «просто лучше».
5. Ось баланса — ТТК (HP 100, без брони) и дальность.

### Токарный станок («очиститель», обратный переработчику)
Ставится на базе, крафт у верстака 2. Работает как печь: кладёшь детали — получаешь деталь выше. Шумит. Рецепты — в таблице выше. Детали тира 3 — только у станка рядом с верстаком 3.

## Изучение (лом, ветки как в Расте)
Ветка «Пистолеты и ПП»: Наган 50 → Самоделка 90 → Грач 120 → ППС-43 150 → ППШ 250.
Ветка «Винтовки»: Арбалет 30 → СВТ-40 150 → АКМ 300 (через Грач или СВТ) / АН-94 300 / СВД 300.
Путь до АКМ ≈ Наган 50 + Самоделка 90 + СВТ 150 + патроны 7,62 100 + АКМ 300 ≈ **690 лома**.
Обвесы и патроны — отдельные узлы по 30–120 лома.

## Где берётся оружие (способы)
1. **Крейты РТ по тирам** — корпуса и детали; на РТ 1 с малым шансом готовые лутовые стволы (Обрез, МР-133).
2. **Бочки и ящики на РТ и дорогах** — общие детали, изредка Самопал, патроны 12к, линза/плата.
3. **Охрана РТ** — иногда роняет своё оружие (самопал/наган у охраны тира 1).
4. **Ивенты режиссёра:**
   - **Аирдроп «кукурузник»** (есть) — детали тира 2–3, армейские обвесы.
   - **Закрытый ящик** (есть) — держать E, шумно.
   - **Инкассаторский УАЗ** — разбитая машина на дороге, вскрыть сейф 60 с (сигнализация): патроны, стволы тира 2.
   - **Сбитый вертолёт** — горящие обломки, 2 военных ящика: детали тира 3, шанс на Сайгу/АПС.
   - **Эшелон** — на ветке у Депо встал состав, вагоны вскрываются по одному, охрана: много деталей тира 2.
   - **Мародёры** — конвой NPC идёт по дороге с лутом; перехватить и забрать.
   - **Схрон по радио** — слух с примерными координатами, закопанный ящик в лесу (лопата/руки, 20 с).
   - **Гуманитарка** — маленький сброс еды и медицины у побережья.
5. **Токарный станок** — детали выше из деталей ниже.
6. **«Объект 42»** — элита и легендарные компоненты (позже).
7. (Позже) **Барыга** на нейтральной РТ.

## Темп вайпа
Цель: тир 1 — 30–60 мин; тир 2 у сильных — 2–4 ч; **первый ствол тира 3 через верстак — 6–8 ч**; массово — второй день. Держим: ствольная коробка АК только лутом (РТ 2, аирдроп, вертолёт), режиссёр выпускает детали тира 3 с середины вайпа и дозирует в час, износ + ремонт маслом/деталями, дорогие 7,62/5,45, фулл-лут. Проверка — прогоны ботов (летопись: первый ствол каждого тира).

Для каждого ствола, компонента, обвеса, патрона и ивента (самолёт, контейнер, УАЗ, вертолёт, вагоны, схрон): иконка 64×64 + спрайт в руках / в мире. «Мужицкий смак» — детально, потёрто, советско, на тёмном фоне читается. Генерация через Codex (scripts/gen-assets.ps1).
