# Раствордд — как подключиться к проекту

Top-down 3/4 выживач (Godot 4.7.2 .NET, C#), пиксель-арт, боты-«игроки», РТ (рейд-точки) с лутом.
Правила для ИИ-агентов и все команды — в `AGENTS.md`. Суть игры — `docs/00-vision.md`, решения — `docs/decisions.md`,
дизайн по системам — `docs/design/`, что сделано последним — `docs/handoff.md`, планы — `docs/roadmap.md`.

## Установка (один раз)
1. Поставить: **Git** (git-scm.com, всё по умолчанию), **.NET SDK 8** (dotnet.microsoft.com), **GitHub Desktop** (desktop.github.com) — по желанию.
2. Склонировать репозиторий (GitHub Desktop → File → Clone, или `git clone <ссылка>`).
3. Запустить **`Установка.cmd`** в корне — скачает движок Godot 4.7.2 .NET в `tools/godot` и соберёт проект.
4. Играть: **`Играть.cmd`**. Полигоны и наблюдение за ботами — остальные `.cmd` в корне.

## Каждый день — две кнопки
- **`Получить.cmd`** — забрать изменения напарника. Запускать ПЕРЕД началом работы.
- **`Отправить.cmd`** — отправить свои изменения (спросит короткое описание). Запускать, когда закончил кусок.
- Если скрипт пишет «КОНФЛИКТ» — ничего не трогать, открыть Claude Code в папке проекта и написать: «разреши конфликт git».

Можно вообще не трогать git руками: в Claude Code достаточно сказать «получи обновления» / «закоммить и отправь».

## Как работать вдвоём без боли
- **Делить зоны**: кто-то на РТ/луте/ботах, кто-то на интерфейсе/звуке. Хуже всего — оба одновременно правят `game/src/Client/Main.cs`, `Hud.cs`, `Sim/World.cs`.
- Перед крупной задачей — написать напарнику, какие файлы трогаешь.
- Отправлять почаще маленькими кусками (раз в час-два), а не раз в неделю.
- Новые идеи и решения — в `docs/ideas-log.md` / `docs/decisions.md`, а не только в чат с ИИ: тогда ИИ напарника тоже их знает.
- Сейв игрока (`%APPDATA%\Godot\app_userdata\Rastvordd\world_save.json`) у каждого свой, в git не идёт.

## Что НЕ в репозитории
- Движок Godot (`tools/`) — ставит `Установка.cmd`.
- Сырые звуковые библиотеки (`audio_src/new_sounds/`, ~3 ГБ) и сборки (`build/`, `dist/`) — у владельца локально.
- Генерация картинок (`scripts/gen-assets.ps1`) работает через залогиненный Codex у владельца.

## Флаги запуска (после `--`)
`--bots=N` боты · `--spectate --autocam` наблюдение (Tab — следующий бот, F — свободная камера, C — автокамера, 1–6 и +/− — скорость до ×60) ·
`--sandbox=aim` стрельбище · `--rigset=hero` новый персонаж · `--rtkit` набор для РТ · `--uitheme=a|b|c`, `--uilayout=1|2|3` варианты интерфейса ·
`--savefile=user://имя.json` отдельный сейв (ставить всегда в тестах). F1 в игре — админка (телепорты по РТ), F6 — настройка рига.
