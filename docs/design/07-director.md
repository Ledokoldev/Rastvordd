# 07 — Директор вайпа, ивенты, экономика

## Директор (аналог рассказчика RimWorld)
Три рычага:
1. **Фаза вайпа:** ранний (фарм, мелкие РТ) → средний (крупные РТ, закрытые ящики) → поздний (рейды, большие ивенты). Фаза меняет ивенты и поведение ботов.
2. **Напряжение:** следит, давно ли рядом с игроком что-то происходило. Скучно → ивент или бот в сторону игрока. Только что еле выжил → передышка.
3. **Волны:** когда и каких ботов добавить (баланс архетипов, реакция на силу игрока: база разрослась → пара рейдеров).

## Ивенты
- **Закрытый ящик:** взлом по таймеру, о нём узнаёт вся карта (боты тоже). Держи точку.
- **Карго / крупный ивент:** по расписанию директора с элементом случайности.
- Вертолёт, аирдропы и т. п. — позже.

## Торговцы → замена (выбрать)
- **Чёрный рынок с доставкой:** заказал → сброс в точку, которую видит вся карта. Беги забирать, пока не перехватили.
- **Контракты директора:** «донеси лут с военки в точку X», «убей бота с наградой за голову». Создают потоки игроков и стычки.
- **Переработчик** в спорных точках (лут → компоненты).
Важно: «реализация» лута должна сама быть рискованной, а не нажатием кнопки у NPC.
