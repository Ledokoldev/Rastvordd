# 09 — Техническая основа

## Движок
Godot 4.7.2 .NET (C#, .NET 8) — предложено. Причины: ~0,5 ГБ на диске (на C: свободно ~16 ГБ), без аккаунта, MIT, текстовые сцены, сборка и запуск из командной строки (агенты могут работать сами), есть 3D, сеть (ENet) и импорт FBX.

## Архитектура
- **Симуляция отдельно от отображения.** Мир, бой, лут, боты — чистый C# на сервере с фиксированным тиком (20–30 Гц). Ноды Godot только показывают состояние и собирают ввод.
- **Одиночная игра = локальный сервер + клиент** в одном процессе. Мультиплеер потом — тот же сервер по сети.
- Клиент шлёт ввод (движение, прицел, действия), сервер присылает состояние. Предсказание движения на клиенте — позже, для сети.

## Железо пользователя (2026-10-20)
i5-12400F, 32 ГБ RAM, RTX 4070 Ti. Диск C: ~16 ГБ свободно.

## План этапов
0. Прототип ощущений: камера сверху, персонаж WASD + мышь, стрельба, попадания, смерть, лут с трупа, сетевая основа (локальный сервер).
1. Выживание: голод, вода, HP, кровотечение, фарм нод, инвентарь, крафт, верстаки.
2. Строительство: сетка, уровни, двери, замки, шкаф, рейдовые средства.
3. Мир: процедурная карта, биомы, префабы РТ, простые NPC.
4. Первый бот-игрок проходит весь цикл с учётом архетипа.
5. Экосистема: архетипы, дуо, волны, директор, ивенты, закрытые ящики.

## Клиент (2026-10-20)
- 2D, вид 3/4 (Node2D + y-sort). Проекция: земля сверху, 1 м = 32 px, высота × 0.75. Курсор указывает на высоту оружия (точка на земле = курсор + GunH).
- Персонаж: 2 уникальные позы (лицом / спиной), левые — зеркало. Оружие — отдельный узел, вращается на 360°; при взгляде вверх рисуется за телом.
- 3D-клиент (первая версия) остался в истории git, коммит 2ceee59.
- Запуск со скриншотом: `-- --shot=путь.png --frames=N --spawn=x,y --aim=x,y --zoom=z`.
- Замечено: охранники РТ слишком меткие (убивают стоящего игрока за ~5 с) — подстроить.
