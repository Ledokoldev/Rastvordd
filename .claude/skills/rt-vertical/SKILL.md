# Вертикаль (этажи) в РТ

## Что уже умеет движок (D60)
- `Floor`/`Z` у людей, построек, ящиков, сумок, пуль; сетка стен на каждый этаж; контекст этажа `World.Ctx(f)`.
- Лестница (подъём по клетке, этаж переключается на середине), люк (E), падение с урона (высота − 2,2 м) × 20.
- Пули и обзор в объёме (`ClearLine3`, `StepBullet3`): пол держит, стены — по высоте, проёмы пропускают.
- Взрыв: свой этаж и перекрытие над собой (60 %). Клиент: верх выше по экрану, срез этажей под крышей.
- Для РТ нужно добавить: плиты `MapSlab` любой формы, марши `MapStair`, высота этажа РТ, этаж у декора/крыш/света,
  порталы отдельных локаций, граф лестниц (29-multistorey-rt.md, раздел 4).

## Правила вертикали
1. **Вертикальный цикл**: внизу/у входа — быстро и дёшево, наверху/в глубине — дорого, путей туда 1–2 (у малых)
   или ≥ 2 разных (у больших).
2. **Вертикальный вход — с ценой информации**: у того, кто наверху, не может быть сразу обзор, укрытие и лёгкий отход.
   Дай нижнему контригру: шум шагов по железу, люк, в который летит бомба, пролёт, откуда видно ноги.
3. **Стрельба между этажами — только через «окна в вертикали»** (атриум, пролёт, решётка, край балкона, разбитый пол).
   1–2 на этаж, видны издалека.
4. **Минимум два пути на этаж** у больших РТ (две лестницы в разных концах или лестница + люк/лифт).
5. **Быстрый опасный выход** у дорогого этажа: прыжок (урон), трос, провал; **медленный безопасный** — лестница.
6. **Шум**: железный марш, лифт, люк — слышно на 2 этажа; бетонная лестница тише. Через плиту звук глуше (−12 дБ).
7. **Читаемость в 3/4**: свой этаж активный; этаж над головой — контур 10 %; ниже — затемнён; у каждого этажа своя
   палитра пола и табличка с номером; лестница подсвечена; карта и миникарта по этажам; HUD «Этаж 2 / 3».
8. **Высота этажа** РТ — 4 м (пользователь), постройки игроков — 2,6 м; лестничный марш 4 м ≈ 5 м пути.
9. **Высота не открывает карту**: обзор ограничен радиусом; на острове — до 2 (редко 3) этажей, выше — отдельная локация.

## Формат этажей в макете
```
"floors": [ { "z": 0, "slabs": [...], "walls": [...], "props": [...], "crates": [...], "guards": [...], "roofs": [...], "lights": [...] } ],
"stairs": [ { "a": [x,y], "b": [x,y], "w": 2, "lo": 0 } ], "hatches": [...], "lifts": [...], "voids": [...]
```
Сначала **вертикальный скелет** (лестничные клетки, шахты, атриумы — соосны на всех этажах), потом планировка этажей.

## Проверка
- `--floortest` (механика), скрин-прогоны на каждом этаже (`--house2`-подобный флаг для РТ), стрельба из каждого
  «окна в вертикали», бот/охранник проходит лестницу без зависания.
