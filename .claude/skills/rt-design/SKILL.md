# Проектирование РТ (Раствордд)

РТ — не «комната с ящиками», а **система риска**: зачем идти, как войти, что увидишь, что услышат другие, как уйти.
Опоры игры (docs/00-vision.md): рейд, закрытый ящик, кемп лутеров, вынести лут, карго/ивенты, живые боты.
Источники: см. `docs/level-design-library.md` (белая книга по картам экстракшн-шутеров, level-design из
gamedev-skills, Level Design Book). Здесь — выжимка под наш вид сверху 3/4 и наши системы.

## Порядок работы
1. **Роль.** Тир (0–3), что даёт экономике (D49: лом, детали, перфокарта следующего тира), какую опору усиливает.
   Тир 3 — память игрока: сильный ориентир, сильная награда, сильная цена.
2. **Топология раньше картинки.** Граф: входы → зоны (низкий/средний/высокий риск) → главная цель → выходы.
   Три класса маршрутов: быстрый-опасный, средний-управляемый (точки решения «дальше или уйти»), медленный-тихий.
3. **Сценарий входа главной цели** (8 вопросов): зачем идти; откуда войти; что видно до входа; что выдаёт вход;
   как обыскивать; как драться; как отступить при провале; как уйти при успехе.
4. **Входы разные по цене**: парадный (быстро, простреливается), боковой (обход, длиннее), вертикальный (крыша, люк,
   шахта — см. rt-vertical), шумный (железная дверь, сирена, лифт — вход становится событием для всех).
   У высокоценной зоны — **≥ 3 направления входа и ≥ 2 отхода**.
5. **Внутри**: «понятная ось + сложные комнаты + короткие петли». Ни чистый лабиринт, ни пустой зал.
   Прострел 8–18 м внутри, наружу — до радиуса обзора (50–80 м) и только с ценой (позиция видна, отход труден).
6. **Лут — язык маршрута** (rt-pve-loot): по виду ящика понятно, что внутри; стабильное — на средних зонах,
   «потолок» — в горячей.
7. **Охрана — темп риска, а не мебель** (rt-pve-loot): охраняет, шумит, тратит патроны, выдаёт игрока, меняет маршрут.
8. **Выход** (rt-extraction): ≥ 2 пути с разной ценой, у кемпа есть цена.
9. **Темп** (rt-layout-check): список «битов» с интенсивностью 0..1, пила с отдыхом перед пиком.
10. **Проверка** чек-листом ниже, потом — макет (`scripts/mock-tier*.py` → `Tier*Layouts.g.cs`), скрин-прогоны,
    прогон ботов (`--simtest`), вопросы пользователю для плейтеста.
11. **Одевать последним** (обстановка `Dressing.cs`, ассеты Codex/«Астра»).

## Дистанции боя (наши стволы)
| Дистанция | Где | Кто силён |
|---|---|---|
| 0–15 м | комнаты, лестницы, проходы | дробовики (MP-133, Сайга), ПП (ППС, ППШ) |
| 15–35 м | дворы, цеха, палубы | всё; основной бой |
| 35–80 м | дороги, площадки, крыши | АКМ, СВТ, АН-94 |
| > 80 м | нет: обзор кончается раньше | — |

## Наши ограничения (не нарушать)
- Туман войны D10/D32: честный обзор; высота не открывает карту (радиус обзора тот же).
- Охрана РТ не фулл-лут (D35); ценное — по бюджету режиссёра (D49).
- Действия у ящиков — «рукой» (E), сквозь стены нельзя.
- Многоэтажные РТ: на острове — низкие (2, редко 3 этажа), высокие/глубокие — отдельные локации (29-multistorey-rt.md).
- Слова пользователя записывать в docs/ideas-log.md, решения — docs/decisions.md.

## Чек-лист приёмки
| Что | Годно | Тревога |
|---|---|---|
| Входы в горячую зону | ≥ 3 направления, разная цена | одна дверь/лестница — мясорубка |
| Отход | ≥ 2 пути, быстрый-открытый и медленный-скрытый | только назад тем же путём |
| Шум | ценное действие слышно (дверь, лифт, взлом) | топ-лут забирают молча |
| Читаемость | двери, окна, стены, ящики — стабильный язык | непонятно, пробивается ли/открывается ли |
| Дистанции | есть 0–15, 15–35, 35–80 | один тип ствола решает всё |
| Высота | у высокой позиции есть цена (видна, трудный отход) | наверху и обзор, и укрытие, и отход |
| Слабый старт | есть дешёвый вход и малый лут на краю | голый игрок умирает без шанса |
| Экономика | потолок высокий, но с ценой | «быстрая ферма»: забежал-взял-ушёл без риска |
| Боты | бот проходит РТ своими действиями (World.BotRt.cs) | бот застревает (`scripts/bot-stalls.py`) |

## Метрики после запуска (летопись, `--simtest`)
Время первой встречи, смертность по зонам, посещаемость зон, доля унёсших лут, убийства у выходов, ценность в час.
