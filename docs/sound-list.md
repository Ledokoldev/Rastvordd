# Список звуков для «Раствордд» (делает пользователь)

Я звуки не делаю — в игре стоят заглушки из того, что уже есть. Ты делаешь файл с **точно таким именем** и кладёшь в `game/audio/` — игра сама подхватит его вместо заглушки.

Формат: WAV или OGG, 44,1/48 кГц, моно для звуков в мире (направление и расстояние считает игра), стерео только для интерфейса и фоновых петель. Без длинной тишины в начале. «×3» — сколько вариантов (`_01`, `_02`, `_03`), игра выбирает случайно.

Колонка «Сейчас» — какая заглушка звучит.
