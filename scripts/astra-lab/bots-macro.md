ЗАДАЧА: макро-ИИ ботов-игроков — СТРОЙКА, РЕЙДЫ, ВЗАИМОДЕЙСТВИЕ, ИГРОВЫЕ МЕХАНИКИ (не стрельба и не отдача).
Цель — боты живут вайп как сильные игроки Раста: быстро строят нормальную базу, развиваются, рейдят и защищаются, пользуются механиками.

Инструменты (уже есть):
- Прогон вайпа headless: `<godot>_console.exe --headless --quit-after 20 --path game -- --simtest=28800 --bots=12 --chronicle=<путь>.jsonl > <путь>.log`
  (28800 c игрового времени; можно меньше для быстрых итераций). `<godot>` — `C:\Users\Xbaza\Desktop\Rastvordd\tools\godot\Godot_v4.7.2-stable_mono_win64\Godot_v4.7.2-stable_mono_win64`.
- Разбор: `python scripts/bot-rust-metrics.py прогон.jsonl прогон.log`, `python scripts/bot-stalls.py прогон.log` (где боты застревают),
  `python scripts/wipe-report.py прогон.jsonl отчёт.html`. Если Python в песочнице недоступен — разбирай .jsonl/.log сама (rg/PowerShell).
- Мозг ботов: `game/src/Sim/PlayerBot*.cs` (Base, Raid, Greed, Hostility, Brain, Lathe…), дизайн — `docs/design/bot-brain.md`, прошлые разборы — `docs/bot-review-*.md`.

Цикл самосовершенствования (повторяй, пока есть время):
1. Прогон вайпа → метрики: время до шкафа/первой базы/верстаков 1–3, качество базы (слои стен, двери, сота, шкаф внутри), содержание
   (не гниёт ли база), рейды (сколько, успешность, окупаемость взрывчатки), защита (возврат домой при рейде), простои/застревания,
   использование механик (печи, переработчик, токарный, электричество, погода — укрытие в буран, РТ-походы, торговля/взаимодействие с соседями).
2. Найди 2–3 главные слабости по цифрам (журнал ошибок/застреваний, что делают хорошие игроки иначе).
3. Исправь в мозге ботов (конкретные правки целей/приоритетов/планов стройки), сборка 0 ошибок.
4. Повторный прогон с тем же зерном и сравнение «до/после» таблицей. Хуже — откати.
Пиши результат каждой итерации в `docs/astra/bots-macro-results.md` (таблица метрик до/после + что поменяла) и строку в `docs/astra/LOG.md`.
Работай только в этой копии (`astra-bots`), коммиты не делай.
