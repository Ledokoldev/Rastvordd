## Сделано за сессию (коротко)
**Интерфейс:** инвентарь как в Arc Raiders (24 ячейки, стаки, перетаскивание, Shift-ховерлут, выброс за окно), обыск ящиков РТ и трупов по ячейкам один раз, лента подборов, описания предметов, окна по E (печь, ящик, шкаф, переработчик), крафт сеткой с вкладками и очередью, дерево изучения на верстаке (лом, верстаки 1–3), минималистичный стиль, миникарта, подсказка прочности построек.

**Стройка:** умный План (на фундаменте — стена, на проёме — дверь), колесо по ПКМ, полоска элементов, цены в 4–6 раз ниже растовских, **треугольные фундаменты** с наклонными стенами и дверями (рёбра — пары вершин).

**Мир и экономика:** бочки с хламом и кучи хлама (лом), детали + переработчик, сейф под карту доступа на РТ с охраной, охрана без фулл-лута (оружие не падает), античит видимости (E только «рукой», туман войны для чужих баз).

**Боты:** поиск пути A* (сетка 0,25 м, через свои двери — открыть/закрыть), прогрессия до верстака 3 и всего дерева, самопалы, рейд бомбами по двери; **мозг v2**: доска знаний, директор целей с весами архетипа, слух выстрелов и взрывов с решением «иду/не иду: причина», антирейд, журнал мыслей; **чертежи баз** по стадиям (кибитка → мейн → соты → финал с металлом), 3 плана по характеру.

**Инструменты:** режим наблюдателя (`--spectate`), вехи и мысли в логе прогонов, переносная сборка для виртуалки.

## Состояние на конец сессии
- Прогон 60 мин: фермеры ставят кибитку к 5-й минуте, мейн к 18-й, соты к 36–50-й, верстак 2 к 36–47-й; зависаний дольше минуты нет.
- Не проверено вживую: «идти на выстрелы» и антирейд (в прогонах не возникали), план «Треугольная» (не выпадал по характеру), финальная стадия с металлом.
- Рейд честным путём — дольше 2 часов (≈300 пороха на каменную дверь); баланс взрывчатки не трогали — решение за пользователем.
