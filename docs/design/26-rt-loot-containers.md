# РТ как кусок Arc Raiders — лутаемый интерьер (решения 26.10)

## Принципы
- Лутаемый элемент — часть интерьера, который **всегда и только** лутается: такой же предмет никогда не стоит как декор.
- Реальные цвета (как в жизни), трафарет-иконка содержимого, крупный и массивный — ничего мелкого; в одном доме / части здания их может быть много.
- Состояния: закрыт / открыт (пустой) — сразу видно, залутан ли.
- Два класса:
  - **Обыск** — подошёл, E, ячейки открываются по таймеру (как сейчас у ящиков).
  - **Вскрытие** — подошёл, ЗАЖАТЬ E: за N секунд вскрывается со звуком (шум слышен вокруг), потом обыск. Внутри лучше.
- Компоненты двух тиров: базовые по контейнерам, основные — главный крейт и комната за стеной.
