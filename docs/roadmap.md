# Роадмап «Раствордд» (на 2026-10-21)

Порядок — по важности для опор игры. Каждый пункт заканчивается проверкой в игре.

## Сделано
- **Этап 0.** Сервер-авторитарная симуляция (локальный сервер в одном процессе), WASD + мышь, стрельба с разбросом, туман войны на сервере, охранники РТ (присматриваются, неточные первые очереди), лут с трупов и ящиков, смерть и пляж.
- **Камера и обзор.** Вид 2D 3/4, 4 диагональные позы (левые — зеркало). ПКМ — прицеливание (уже конус, дальше обзор, меньше разброс, медленнее шаг). Спринт только вперёд.
- **Этап 1.** Голод/вода (лёгкие), ресурсные узлы, пояс 6 слотов, крафт по Q с очередью, печь (руда → металл/сера, уголь), верстак, установка ЛКМ.
- **Арт.** Конвейер Codex → пикселизация (32 px/м, общая палитра) → игра. ~120 ассетов: деревья, руды, растения, предметы, 13 тайлов земли/стен, 60+ иконок, 25 видов оружия, огонь, декали.
- **Мир.** Остров 400×400 м с биомами (поле, лес, тайга со снегом, пустошь, болото, пляж), вода непроходима, ресурсы по биомам, спавны на пляжах. Земля одним шейдером: рваные переходы, рельеф светотенью по высотам, пена у берега.
- **Свет.** Смена дня и ночи (20 мин на сутки), ночью обзор на 40% короче, свет от печи и вспышек выстрелов.
- **Звук.** Синтезированные заглушки: выстрелы, удары по дереву/камню/руде, взмах, попадание, шаги по траве/гравию, лут, крафт, треск печи; фон — ветер, прибой, птицы днём, сверчки ночью.
- **Персонаж.** Сгенерированный лист ходьбы (4 кадра лицом, 4 спиной) для игрока («голый») и охраны РТ (брезент, сталь на груди).

- **Мир ожил.** Трава и деревья по биомам, камни/укрытия/растения стилизованы под биом, мелочи и цветы, ветер, частицы (листья, снег, пыль, светлячки).
- **Обзор как в Project Zomboid.** Только конус, тени от стен и стволов, серым — только мир, персонажи не затеняются.
- **Присед (Alt).** Медленнее, тише, точнее, прячет за низкими укрытиями.
- **Звук.** Сэмплы пользователя (выстрел, перезарядка, шаги бетон/трава/снег с растяжением без смены высоты), акустика (задержка, окклюзия, эхо места, дальний слой), бинаурал на 16 направлениях. Админка F1.
- **Анимации оружия (стиль Gungeon).** Отдача, гильзы, перезарядка с выпадающим магазином, смаз удара, две кисти.

## Дальше (после квиза 2026-10-21, решения D18–D26)
1. **Свои названия.** Список «растовское → наше» для предметов и построек, пользователь утверждает, потом замена в коде. Делаем до строительства, чтобы постройки сразу получили свои имена.
2. **Этап 2 — строительство и рейды.** ✅ Первый срез сделан (ночь 2026-10-21): клетка 2 м; план постройки (R — элемент, ЛКМ — поставить) и молоток (улучшить/починить); фундамент, стена, дверной проём, окно (пули и взгляд проходят), дверь; 5 состояний: разметка → дерево → камень → металл → сталь; межевой столб: зона 8 клеток, зазор 21, бюджет 360 / фундаменты 160 / двери 48, содержание 4%/ч с отсрочкой 30 мин и гниением; урон: инструмент — разметка и дерево, пули — разметка и двери, взрывчатка — всё (камень 2 шашки, металл 4, сталь 8); связка (осечки) и шашка с часами; кодовый замок; срез стен изнутри дома, как в Zomboid. **Осталось:** замок с ключом, ящики-хранилища, огонь по дереву, опоры (пролёты), крыша/второй этаж не нужны (один этаж), спальник, ремонт после рейда без молотка-спама.
3. **Сохранение мира.** ✅ Автосохранение раз в минуту, F5, при выходе; загрузка при запуске (user://world_save.json).
4. **Производительность и большая карта.** ✅ Пространственная сетка (коллизии, обзор, пули, снапшоты): симуляция ×3 быстрее; стресс-тест 2×2 км — 18 тыс. узлов, 165 fps, 0,13 мс/тик. ✅ Остров 1×1 км, биомы пятнами (снег, сушь, лес, поле, болото). Плавание ✅ (×0,45 скорости, без оружия, по пояс в воде). Осталось: 2×2 км.
5. **Этап 4 — первый бот-игрок.** ✅ Начато: 2 бота-«фермера» (Сёма, Жека) — голый старт → фарм → топор/кирка → столб → дом 2×2 с дверью → дерево → ящик → кормят столб, едят/пьют, убегают от вооружённых. **Дальше:** остальные архетипы, ставка (кит+груз), бой, рейды ботов. Голый старт → фарм → база по шаблону → РТ → бой; ставка (кит + груз) решает, драться ли. Сценарии — `docs/gpt/03-bot-scenarios.md`.
6. **Досчёт офлайна.** ✅ Базово: столбы едят запас, гниение без запаса, респавн ресурсов, отчёт «Тебя не было…». Боты офлайн пока не действуют. При запуске упрощённая симуляция пропущенного времени: что боты нафармили, построили, кого зарейдили.
7. **Больше РТ + спорный переработчик.** ✅ 5 малых РТ по карточкам Астры (Весовая, Раздаточная, Почтовый узел, Котельная, Станция семян) — забор, постройка, укрытия, ящики, охрана по карточке, бетонный двор, название при входе. Осталось: средние/крупные РТ со своей планировкой и механиками (пропуска, рубильники), переработчик.
8. **Этап 5 — экосистема.** Архетипы, дуо, волны, директор вайпа, закрытый ящик, карго. Транспорт (для 2 км).
9. **Одежда и броня (свои, не растовские), медицина.** Персонаж в одежде, кадры удара/стрельбы. Факел/фонарь ночью.
10. **Звуки.** Сэмплы от пользователя (`audio_src/`) вместо синтеза.
11. **Сеть.** Тот же сервер за ENet.

Настраиваемое в вайпе: длина суток, размер карты, (позже) число ботов.
