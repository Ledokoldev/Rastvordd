# Задача для Астры: альтернативы компонентам и рецептам — ближе к реальности

Контекст: игра «Раствордд» (постсоветский остров 1980-х, выживание в духе Rust, тиры 0–3). Твой прошлый документ —
`docs/design/19-components.md` (+ `19-components.json`). Прочитай его и `docs/design/13-weapons-progression.md`, `docs/design/15-economy.md`.

Сейчас это **только концепты** — в код ничего не идёт. Думай как геймдизайнер, который любит правдоподобие.

## Что сделать — `docs/design/22-components-alt.md`
1. **Реалистичность рецептов.** Для каждой цепочки из 19-го документа (оружие, броня, медицина, взрывчатка, электричество/топливо, стройка, инструменты, лодка) предложи вариант, **приближенный к реальным технологиям**: как это делали бы в гаражной/колхозной мастерской или на заброшенном заводе (например: ствол — из трубы бесшовной + токарка + нарезы протяжкой; порох — нитроцеллюлоза из ваты и кислот, проще — охотничий порох из лута; бронепластина — термообработка стали; аккумулятор — из автомобильного; бинт — кипячёная ткань; антирадин — йодистый калий). Где реалистичное слишком сложно для игры — честно упрости и напиши, что упрощено и почему.
2. **Логичные альтернативы.** Для каждого компонента/рецепта, где это имеет смысл: 1–2 альтернативных пути получения или замены (дешёвый-плохой ↔ дорогой-хороший; самодел ↔ заводской из лута), с обоснованием, чем отличаются в игре (качество/износ/шанс отказа/время/шум/запах).
3. **Сокращение без потерь.** Отметь компоненты, которые можно слить или убрать без потери интересных решений (цель — меньше, но осмысленнее), и 5–8 «стержневых» компонентов, на которых держится экономика.
4. **Таблица сравнения:** текущий вариант (19) → реалистичная альтернатива → что меняется для игрока → рекомендация (оставить / заменить / дать оба пути).
